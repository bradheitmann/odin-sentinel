## 7. Gotchas
- Scratch copies: `cp -R` of a linked worktree shares the real index (`git add -N` in the copy staged entries in the real worktree). Use `git clone`.
- Pi dispatches: a dispatch can echo into the input bar and never be submitted (one QA dispatch sat there three and a half hours). After every Pi dispatch, read the screen for a Working line, not only the send result.
- Pi's command gate refuses a revision command combined with `&&`, pipes, heredocs or `VAR=` prefixes. Pattern: message file, `git add <path>` alone, the plain command alone; a small wrapper script for an exported variable.
- `perl -CSD -pe` with non-ASCII text typed in the replacement double-encodes it (an em dash became mojibake in STATE). Add `-Mutf8` or keep replacements ASCII, and grep for the byte 0xC3 0xA2 after an edit.
- `tests/scripts/sync-installations.test.ts` can time out under host load; re-run the file alone, never widen a timeout in the repository. tests/audit is stable.
- odin-say results: exit 5 or 6 with `INPUT_BAR_ONLY` means the text was typed but not acknowledged: read the screen, never resend blindly. A wrapper timeout that kills odin-say during its wait sent nothing (no record in the delivery proof log): send once after.
- `charter receipt` validation depends on the working directory: outside a charter tree exit 0 is structural only; inside, a fresh accepted receipt is refused until the PM records `charter reopen`. Record both, never only the flattering one.
- Fleet pins move often: before trusting an earlier "strict ok", read the current row of ~/.local/share/charter/PINS.tsv.
- Never echo environment variables or keys in a seat terminal (an attest private key once passed through one and was rotated).
- `grep -c` exits 1 on zero matches and silently breaks `&&` chains.
- holden prints absolute machine paths in some refusals and in `ledger verify`; pipe its output through `sed "s|$HOME|~|g"`. Same-named clones share holden host state: keep clone folder names unique.
